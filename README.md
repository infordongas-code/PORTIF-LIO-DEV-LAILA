# Portfólio dos Alunos

Projeto-base de um portfólio pessoal desenvolvido com:

- HTML5
- CSS3
- JavaScript
- Menu responsivo
- Design responsivo para celular e computador

## Estrutura do projeto

```text
portfolio_alunos/
├── index.html
├── README.md
├── css/
│   └── style.css
└── js/
    └── script.js
```

## Como abrir no VS Code

1. Baixe o arquivo ZIP.
2. Extraia a pasta `portfolio_alunos`.
3. Abra a pasta no Visual Studio Code.
4. Abra o arquivo `index.html`.
5. Clique com o botão direito no `index.html`.
6. Escolha **Open with Live Server**.
7. O portfólio será aberto automaticamente no navegador.

## Personalização

No arquivo `index.html`, altere:

- `Seu Nome` pelo nome do aluno.
- A seção **Sobre mim** com informações pessoais.
- As **Habilidades**.
- Os **Projetos**.
- A **Formação**.
- Os dados da seção **Contatos**.
- O link do GitHub e Instagram.

Também é possível trocar as cores e o visual no arquivo:

`css/style.css`

## Observação

O projeto não precisa de banco de dados ou servidor para funcionar.

Basta abrir o `index.html` com o Live Server.
